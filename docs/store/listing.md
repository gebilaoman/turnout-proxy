## 1. 商品详情（Store listing）

**语言**：中文（简体）

**名称**（来自 manifest，不可在控制台修改）：Turnout – Proxy Switcher

**摘要**（manifest `description`，≤132 字符）：

> 多个本地代理客户端一键切换，规则配一次对所有客户端生效，状态一目了然。

**说明**（Description）：

```
Turnout 是给同时使用多个本地代理客户端（FlClash、万达云、Clash Verge、v2rayN、ShadowsocksX-NG 等）的人准备的代理切换扩展。

【一键切换】
· 三种模式：智能分流 / 全部代理 / 直连
· 出口可选任一本机客户端，或跟随系统代理
· 首次使用自动扫描本机常用端口，发现已打开的客户端

【规则配一次，所有客户端通用】
· 内置 GFWList 规则，开箱即用，自动在线更新
· 支持自定义 AutoProxy / GFWList 订阅地址
· 「我的网站」：按网站指定直连或走代理，自动包含子域名；在弹窗里对当前网站一键设置
· 全部代理模式下，「直连」条目同样生效，可当直连白名单

【状态一目了然】
· 弹窗显示当前模式、经由哪个客户端、在线状态、延迟和出口 IP
· 「当前网站」说明这个网站现在走哪条路、为什么
· 工具栏图标用颜色区分：正常 / 已切到备用 / 直连 / 异常

【坏了会说清楚】
· 当前客户端离线时，浏览器立即改走备用客户端，并告诉你原因
· 所有客户端都连不上时，默认不会偷偷改成直连暴露真实 IP
· 代理设置被其他扩展接管、规则更新失败，都会给出原因和解决步骤

【配置不丢】
· 配置只保存在本机；可导出导入；升级或导入前自动备份
· 支持从 ZeroOmega / SwitchyOmega 导入代理服务器与规则订阅

【可信赖】
· 开源（GPL-3.0）：https://github.com/gebilaoman/turnout-proxy
· 无遥测、无统计、无广告、免注册
· 不读取网页内容、Cookie 与浏览历史

注意：Turnout 不提供代理服务，需要你在本机运行代理客户端。
```

## 2. 隐私权（Privacy practices）

**单一用途说明**（Single purpose）：

> 管理浏览器的代理设置：在用户本机运行的多个代理客户端之间切换，并按一份规则决定哪些网站走代理。

**权限理由**（每项权限一栏）：

| 权限 | 理由（填写内容） |
| --- | --- |
| `proxy` | 扩展的核心功能：通过 PAC 脚本设置浏览器代理，在本机代理客户端之间切换，并按规则决定哪些网站走代理。 |
| `storage` | 在本地保存客户端列表、模式与规则设置、规则缓存和配置备份。数据不离开用户电脑。 |
| `alarms` | 每分钟检测当前与备用客户端是否在线，以便客户端离线时及时切换；按用户设置的频率定时更新规则订阅。 |
| `activeTab` | 用户点击工具栏图标打开弹窗时，读取当前标签页的网址，用于显示该网站的代理路由并一键设为直连或走代理。不在后台读取，不保存浏览记录。 |
| 主机权限 `http://127.0.0.1/*`、`http://localhost/*` | 检测本机代理客户端（如 127.0.0.1:7890）是否在运行。 |
| 主机权限 `http://connectivitycheck.gstatic.com/*` | 经各个代理客户端请求 generate_204，判断代理是否可用并测量延迟；需要读取状态码以区分 204 与代理返回的错误。 |
| 主机权限 `https://raw.githubusercontent.com/*` | 下载内置规则 GFWList（gfwlist/gfwlist 仓库）。 |
| 主机权限 `https://one.one.one.one/*` | 查询当前代理出口的公网 IP 与国家（Cloudflare trace），显示在弹窗中。 |
| 可选主机权限 `https://*/*`、`http://*/*` | 仅当用户填写自定义规则订阅地址时，按该地址所在域名在运行时申请，用于下载规则；用户可拒绝。 |

**远程代码**：否，我不使用远程代码。
（说明：所有代码随扩展打包；下载的规则订阅只作为数据解析，不会执行；PAC 脚本由扩展本地生成。）

**数据使用**：以下各项均**不勾选**（不收集）：
个人身份信息、健康信息、财务和付款信息、身份验证信息、个人通讯、位置、网络记录、用户活动、网站内容。

并勾选三项声明：
- 不会出于已获批准的用途之外的用途向第三方出售或传输用户数据
- 不会为实现与商品单一用途无关的目的而使用或转移用户数据
- 不会为确定信誉或放贷目的而使用或转移用户数据

## 5. 审核常见问题

- **代理类扩展会进入深度审核**，通常需要几天到两周。权限理由写清楚、与功能一一对应可以减少来回。
- 如被问到 `optional_host_permissions` 范围过大：说明它只在用户填写自定义订阅地址时按单个域名申请，且可拒绝。
- 如被问到内置 GFWList：它是规则数据（LGPL-2.1，原样分发），不是代码。
- 如静态扫描提示包内出现 `Function(`：来自校验库 zod 的特性探测代码，扩展已设置 `z.config({ jitless: true })`，运行时不会调用；且 MV3 的 CSP 本身禁止 eval。
