## 关于 `.dc.html` 格式

这些文件是设计画布的组件格式，不是可直接运行的扩展代码：

- 依赖画布运行时 `support.js`（未包含），直接用浏览器打开时 `{{hole}}`、`<sc-for>`、`<sc-if>` 不会渲染。
- `{{xxx}}` 是由底部 `<script type="text/x-dc">` 中 `renderVals()` 返回的值；`<sc-for list="{{items}}" as="item">` 为列表循环。
- 布局、颜色、字号都写在内联 `style` 里，可直接对照转写为 React / Vue 组件。
- `[方括号]` 内容为占位符：`[端口]`、`[类型]`（万达云客户端待确认）、`[默认规则名]`、`[x.y.z]` 等。
- 延迟、出口 IP（203.0.113.x / 198.51.100.x 为文档保留地址）均为示例数据。

## 交互要点

- 弹窗两个维度：**模式**（智能分流 / 全部代理 / 直连）× **出口**（各客户端 / 跟随系统代理）；直连时出口区置灰。
- 状态卡始终显示当前模式、经由的客户端、延迟和出口 IP。
- 客户端离线：PAC 备用列表自动切到备用客户端，不自动切回（可在设置开启）；全部离线时默认**不**回落直连。
- 被其他扩展接管：禁用切换控件，给出原因和修复步骤。
- 所有客户端都连不上：给出排查步骤；默认不直连，提供手动「临时直连」。
- 不做 LNA（本地网络访问）检测与引导（M0 S2 结论）。
- 规则订阅失败：继续使用上次成功版本，提示原因，提供「通过当前客户端更新」。
